📥 Installation
1. Download BepInEx (Mono)
Use this loader:
Download BepInEx Mono (x64)
2. Install Loader

Extract the zip into your Gorilla Tag game folder
(The folder with the .exe)

3. Run Game Once

Launch the game
This creates the BepInEx folders

4. Install the Mod
Download from discord

Put your J0kerClient_GTAG.dll into:

BepInEx/plugins/
5. Enjoy!
